## 📖 Our Story

We're just a group of friends who were highly motivated to dive deep into **LeetCode** and conquer Data Structures & Algorithms. But as we started grinding, we realized something was missing. Standard spreadsheets were boring, and existing platforms didn't give us that personalized squad feeling.

We needed a **cool, dedicated platform** just for us—a place to mark our daily activity, track our problem-solving progress, maintain our streaks, and see who's dominating the leaderboard. 

So, we built **DSA Squad**. 

This isn't just a weekend project for us; it's going to be a part of our daily lives for a long time as we push each other to become better engineers. 

---

## ✨ Features

- 🦸‍♂️ **Personalized Dashboards**: Track individual progress, total problems solved, and current active streaks.
- 📊 **Squad Leaderboard**: A real-time matrix of everyone's activity. Who's grinding and who's slacking?
- 🏆 **Achievements & Milestones**: Gamified milestones to keep the motivation high.
- 🌓 **Sleek UI/UX**: Custom glassmorphism design, smooth micro-animations, and a beautiful dark-mode by default.
- ☁️ **Cloud Sync**: Powered by Supabase to keep all our progress synced in real-time.

---

## 🛠️ Tech Stack

We wanted to keep things incredibly fast, lightweight, and customizable without the overhead of massive frameworks.

- **Frontend**: Vanilla HTML5, CSS3 (Custom Variables, Flexbox, CSS Grid), Vanilla JavaScript (ES6+)
- **Backend / Database**: [Supabase](https://supabase.com/) (PostgreSQL & Realtime API)
- **Design System**: Handcrafted Dark Theme with "Flame Amber" accents.

## 💻 Running Locally

If you want to spin this up locally to check out the code:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Deepansh-Umar/DSA-Squad.git
   cd DSA-Squad
   ```

2. **Start a local server**
   Since we use ES6 modules, you'll need a simple HTTP server. If you have Python installed:
   ```bash
   python -m http.server 3000
   ```
   Or using Node.js:
   ```bash
   npx serve .
   ```

3. **Open in Browser**
   Navigate to `http://localhost:3000`
